# Finance Analytics Dashboard

A beginner-friendly finance analytics project built with Python, Streamlit, Pandas, and Plotly.

## Features
- Total income, expenses, and net savings
- Date and category filters
- Monthly income vs. expense chart
- Expense category pie chart
- Transaction table and CSV download

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Install packages: `pip install -r requirements.txt`
4. Start the dashboard: `streamlit run app.py`

## Data
`finance_data.csv` contains illustrative sample transactions for demonstration only. Replace it with your own non-sensitive data if needed.

## Research note
This is an educational dashboard, not financial advice or a forecasting model.
